# Institute-of-Electrical-and-Electronics-Engineers---IEEE-CIS-Fraud-Detection-
Fraud detection on the IEEE-CIS transaction dataset using LightGBM &amp; XGBoost. Includes time-aware train/validation splitting (no data leakage), extensive feature engineering (time, amount, frequency encoding, email parsing), class-imbalance handling, and SHAP-based explainability. Evaluated via AUC-ROC and PR-AUC.
